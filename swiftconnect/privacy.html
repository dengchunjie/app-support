Privacy Policy

Last Updated: Oct 17, 2026

Version 1.0.0

1. Introduction

Welcome to SwiftSSH. Your privacy matters, and this policy explains what information the app handles when you use it. In short: SwiftSSH does not collect, transmit, or sell your personal data. Everything you save stays on your Mac or is sent only to the servers you choose to connect to.

2. Data Collection

SwiftSSH does not collect any personal information. There are no accounts, no analytics SDKs, no advertising frameworks, no crash-reporting services, and no tracking of any kind. The app does not send usage data to the developer.

No personal data collected

No analytics or tracking

No third-party advertising SDKs

No cloud account required

3. Local Data Storage

Server profiles (names, addresses, usernames, tags, notes and preferences) are stored locally in a JSON file inside your user Library at ~/Library/Application Support/SwiftConnect/servers.json. App settings are stored in macOS user defaults. The known-hosts file used for host key verification is also kept locally. None of these files are uploaded anywhere.

4. Credentials & Keychain

Passwords and private keys are stored in the macOS Keychain, protected by the operating system. They are never written to the JSON profile file. When a private key is needed for a connection, the app creates a temporary file readable only by your user account and deletes it when the connection closes. You can disable password saving at any time and remove every stored credential with “Forget All Credentials” in Settings.

5. Network Connections

SwiftSSH connects only to the servers you configure. Connection data travels directly between your Mac and your server over SSH/SFTP; there is no intermediary service and no developer-operated backend. Host keys are verified against a local known_hosts file, and a changed key will cause the connection to be refused.

6. Third-Party Components

The app includes SwiftTerm, an open-source terminal emulator, to provide the integrated SSH terminal. SwiftSSH uses the OpenSSH client included with macOS for SFTP transport. These components do not collect or transmit your data.

7. Data Security

Secrets are kept in the macOS Keychain and are protected by your user account. The app does not transmit them to the developer or to any third party.

Host key verification and standard SSH encryption protect each connection. You can inspect the known_hosts file from Settings at any time.

8. Changes to This Policy

If this policy changes, the updated version will be posted on this page with a new “Last Updated” date. Significant changes will be reflected in the app's release notes.
