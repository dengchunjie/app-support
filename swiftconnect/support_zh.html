应用简介

SwiftConnect 是一款原生 macOS SFTP 与 SSH 客户端，专为开发者、系统管理员以及需要管理远程服务器的用户打造。您可以在同一窗口中并排浏览本地与远程文件，使用密码、私钥或 SSH Agent 连接服务器，打开集成终端，直接编辑远程文本文件，并统一管理文件传输。

服务器配置与凭据均保留在您的 Mac 上，无账户、无云端同步、无追踪。

核心功能

view_week

双栏文件浏览器

本地 Mac 与远程服务器并排显示。支持列表、图标和分栏视图，可按名称、大小、日期、类型、权限或所有者排序。

star

服务器收藏

保存服务器名称、颜色、备注、初始目录和标签，支持分组管理，并从最近连接中快速进入。

key

多种认证方式

支持密码、私钥（可带口令）或 SSH Agent 登录。凭据保存在 macOS 钥匙串中。

terminal

集成 SSH 终端

在同一窗口中打开终端会话，无需切换应用即可执行命令。

edit_document

远程文件编辑

直接在服务器上打开文本文件，以内置编辑器修改并通过 SFTP 保存。应用会检查编码和二进制内容，避免文件损坏。

swap_vert

传输队列

上传和下载文件或整个文件夹，支持进度显示、暂停、继续、重试和取消。可设置并发传输数量并保留修改时间。

folder_managed

文件管理

在服务器上新建文件夹、重命名、删除文件，并修改权限（支持递归 chmod）。

verified_user

主机密钥验证

主机密钥记录在本地 known_hosts 文件中；若密钥发生异常变化，连接将被拒绝。

sync_alt

rz / sz 命令传输

在集成终端中直接使用经典的 rz 和 sz 命令收发文件，无需离开当前会话。

sync

本地与远程目录同步切换

可选开启双栏同步：在一侧打开文件夹时，另一侧会自动切换到同名目录，保持两边位置一致。

palette

本地文件差异着色

本地文件名会根据与远程的对比结果着色，突出显示远程缺失或比服务器更新的文件，便于直观对比两边差异。

tune

服务器默认打开方式

可为服务器设置默认以 SFTP 或终端方式打开：在全局设置中选择默认模式，并可针对单个服务器单独覆盖。

常见问题

SwiftConnect 支持哪些协议？

当前版本支持通过 SSH 的 SFTP。协议菜单中还会显示 FTP、FTPS、WebDAV 和 Amazon S3，但这些传输方式尚未提供。

我的密码和私钥存储在哪里？

存储在 macOS 钥匙串中，由操作系统保护，绝不会写入服务器列表文件。您可以在设置中关闭密码保存，并通过“清除所有凭据”删除已保存的全部凭据。

主机密钥验证是如何工作的？

首次连接服务器时，其主机密钥会记录到本地 known_hosts 文件（与 OpenSSH 的 accept-new 行为一致）。若之后密钥发生变化，SwiftConnect 将拒绝连接。服务器正常更换密钥后，可通过“设置 → 显示 known_hosts”检查或编辑该文件。

可以编辑服务器上的文件吗？

可以。文本文件可在内置编辑器中打开，并通过 SFTP 保存回服务器。二进制文件和不支持的文本编码会被阻止，以防文件损坏。

传输队列有什么作用？

所有上传和下载都会进入队列，您可以暂停、继续、重试或取消任务。并发传输数量和数据包大小可在设置中调整。

如何备份我的服务器列表？

服务器列表是 JSON 文件，位于 ~/Library/Application Support/SwiftConnect/servers.json。凭据单独存储在钥匙串中，迁移到另一台 Mac 后需要重新输入密码和私钥。

连接或传输失败时应该检查什么？

请确认主机、端口和用户名，并确保服务器接受您选择的认证方式。传输失败时，请检查目标目录的写入权限，并尝试减少并发传输数量。如果主机密钥发生变化，请检查 known_hosts 文件。
