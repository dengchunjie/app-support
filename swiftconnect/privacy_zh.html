隐私政策

更新时间: 2026-10-17

版本 1.0.0

1. 简介

欢迎使用 SwiftConnect。我重视您的隐私，本政策将说明应用在使用过程中如何处理信息。简而言之：SwiftConnect 不会收集、传输或出售您的个人数据。您保存的所有内容都保留在您的 Mac 上，或仅发送到您主动连接的服务器。

2. 数据收集

SwiftConnect 不收集任何个人信息。应用没有账户系统，不包含分析 SDK、广告框架或崩溃上报服务，也不进行任何形式的追踪。应用不会向开发者发送使用数据。

不收集个人数据

无分析、无追踪

无第三方广告 SDK

无需云账户

3. 本地数据存储

服务器配置（名称、地址、用户名、标签、备注及偏好设置）以 JSON 文件形式存储在您的用户资源库中： ~/Library/Application Support/SwiftConnect/servers.json。应用设置存储在 macOS 用户偏好中。用于主机密钥验证的 known_hosts 文件同样保存在本地。这些文件不会被上传到任何地方。

4. 凭据与钥匙串

密码和私钥存储在 macOS 钥匙串中，由操作系统提供保护，绝不会写入 JSON 配置文件。连接需要使用私钥时，应用会创建一个仅您的用户账户可读的临时文件，并在连接关闭后将其删除。您可以随时关闭密码保存功能，并通过设置中的“清除所有凭据”删除已保存的所有凭据。

5. 网络连接

SwiftConnect 仅连接您配置的服务器。连接数据通过 SSH/SFTP 直接在您的 Mac 与服务器之间传输，不经过任何中间服务，也没有开发者运营的后端。主机密钥会与本地 known_hosts 文件进行校验，若密钥发生变化，连接将被拒绝。

6. 第三方组件

应用内置 SwiftTerm（开源终端模拟器）以提供集成 SSH 终端，并使用 macOS 自带的 OpenSSH 客户端进行 SFTP 传输。这些组件不会收集或传输您的数据。

7. 数据安全

敏感信息保存在 macOS 钥匙串中，受您的用户账户保护。应用不会将其发送给开发者或任何第三方。

主机密钥验证与标准 SSH 加密为每次连接提供保护。您可以随时在设置中查看 known_hosts 文件。

8. 政策变更

若本政策发生变更，更新后的版本将发布在本页面并更新“更新时间”。重大变更也会体现在应用的版本说明中。
