App Overview

SSH Jumper is a native macOS SFTP and SSH client built for developers, system administrators, and anyone who works with remote servers. Browse local and remote files side by side, connect with a password, private key, or SSH agent, open an integrated terminal, edit remote text files, and manage transfers — all in one window.

Server profiles and credentials stay on your Mac. There are no accounts, no cloud sync, and no tracking.

Remote File Editing

Open a text file from the server, edit it in the built-in editor, and save it back over SFTP. Encoding and binary-content checks help prevent accidental corruption.

swap_vert

Transfer Queue

Upload and download files or entire folders with progress, pause, resume, retry, and cancel. Control concurrent transfers and preserve modification times.

folder_managed

File Management

Create folders, rename, delete, and change permissions (including recursive chmod) on the server.

verified_user

Host Key Verification

Host keys are recorded in a local known_hosts file, and the connection is refused if a key changes unexpectedly.

sync_alt

rz / sz Terminal Transfers

Use the classic rz and sz commands directly in the integrated terminal to send and receive files without leaving the session.

sync

Synchronized Browsing

Optionally keep both panes in step: when you open a folder on one side, SSH Jumper opens the matching folder on the other.

Local file names are tinted to highlight files that are missing from or newer than the server, making local and remote differences easy to spot.

Per-Server Open Mode

Choose whether a saved server opens in SFTP or Terminal by default. Set a global preference and override it for individual servers.

Getting Started

2

Connect and browse the remote folder in the right pane while the local pane shows your Mac

4

Frequently Asked Questions

Which protocols does SSH Jumper support?

This version supports SFTP over SSH. The protocol menu also lists FTP, FTPS, WebDAV, and Amazon S3, but those transports are not available yet.

Where are my passwords and private keys stored?

In your macOS Keychain, protected by the operating system. They are never written to the server list file. You can disable password saving in Settings and remove every stored credential with “Forget All Credentials”.

How does host key verification work?

The first time you connect to a server, its host key is recorded in a local known_hosts file (the same accept-new behavior as OpenSSH). If the key changes later, SSH Jumper refuses the connection. Use Settings → Reveal known_hosts to inspect or edit the file after a legitimate server key rotation.

Can I edit files on the server?

Yes. Text files can be opened in the built-in editor and saved back over SFTP. Binary files and unsupported text encodings are blocked to prevent corruption.

What is the transfer queue?

All uploads and downloads run through a queue where you can pause, resume, retry, or cancel tasks. You can change the number of concurrent transfers and the packet size in Settings.

How do I back up my server list?

The server list is a JSON file at ~/Library/Application Support/SwiftConnect/servers.json. Credentials are stored separately in the Keychain, so after moving to another Mac you will need to re-enter passwords and private keys.

A connection or transfer is failing — what should I check?

Confirm the host, port, and username, and make sure the server accepts your authentication method. For transfers, check write permissions on the destination and try lowering the number of concurrent transfers. If the host key changed, review the known_hosts file.
